# 这套 Word 模板的填写位置

底稿来源：用户提供的「【批量下载】游戏名称游戏软件源程序v2.1等.zip」。
两份原文件已直接放在 `templates/`，没有额外的「我的资源」父目录。

## 打开前要知道

原文件都是二进制 Word `.doc`。压缩包文件名中的 v2.1 不代表软件版本，
正文页眉里存在「游戏名称游戏软件V1.0」。以用户提供的版本为准，检查每个节的页眉，
不要把源码中的字符串或第三方依赖版本一并全局替换。

这些文件包含一套游戏的示例材料，不能直接改个名称交付。未提供对应内容时先列缺项。

## 源程序模板

- 开头有大量留白，页眉和页脚有软件名称及页码域。先在文档软件中确认第一页与正文起点。
- 示例源码从 `window.__require = function e(t, n, r)` 开始，包含游戏相关模块。
- 替换正文范围内的示例源码，使用用户指定的真实项目文件；清点并排除依赖、构建产物、密钥和运行数据。
- 保留模板的代码段落格式、纸张设置、页眉页脚。大段粘贴时选择匹配目标格式或纯文本，不带入编辑器的配色与行号侧栏。
- 用户没有给出项目或源码清单时，不复制、改写或生成示例代码来填满文档。
- 页数根据真实源码与确认的提交范围检查，不承诺沿用模板原页数。

|---|---|---|
| 封面、页眉 | 游戏名称游戏软件、V1.0 | 换为用户确认的软件名称、版本；检查不同节和首页 |
| 文件修订记录 | V1.0、2018-12-10、王某、初始版本 | 填真实版本、日期、作者和用户提供的修订说明 |

| 软件编译环境 | Idea、编译成功画面 | 填真实开发工具及实际截图 |

| 排行榜功能 | 好友战绩示例与截图 | 填实际功能或由用户确认替换章节，不凭空添加排行榜 |
| 数据库软件／数据库脚本文件 | MySQL5.6 和示例界面 | 填真实数据库资料；不使用数据库时请用户确认如何填写 |
| 规范文件 | 示例内容区域 | 填用户提供的格式、协议或规范说明 |
| 目录 | TOC 和页码引用域 | 在文档软件中更新整个目录，不能手写猜测页码 |
| 插图 | 原游戏截图和示例图片 | 替换为用户实际软件截图，核对图片文字，不能只改正文 |

## 操作与核对

先复制，再编辑工作副本。系统有可用的 WPS／Word 文档接口时优先使用接口；否则用桌面界面。
查找和替换要覆盖正文、页眉、页脚、表格、文本框；每种位置核对结果，不假设一次「全部替换」涵盖所有位置。

保存后通过同一文档软件导出 PDF。逐页检查源文档和 PDF，尤其是分节页眉、目录、
修订记录、表格、图片和末页，确保导出确实来自填写后的工作副本。
文档软件缺失或导出失败时不要切换成 HTML 重排。

正式文档中不加额外生成说明、工具水印、处理日志或待办清单；需要补充的事项在回复里说明。
原模板内已有的元数据、作者或声明保留其原义，不能通过改动这些信息冒充其他作者。
