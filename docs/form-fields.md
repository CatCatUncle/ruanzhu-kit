# 在线表单逐字段怎么填

中国版权保护中心在线登记系统的字段说明。括号里是 `ruanzhu.config.json` 里 `form` 的键名。

## 基本信息

这几项工具会从配置里自动填进 `表单填写清单.md`，不用手写：

| 字段 | 来源 | 注意 |
|---|---|---|
| 软件全称 | `softwareName` | 末尾带版本号，如「XX管理系统V1.0」；别用简称、别带英文商标 |
| 版本号 | `version` | 与软件全称里的版本号一致 |
| 著作权人 | `copyrightOwner` | 与营业执照／身份证**一字不差**，含行政区划和「有限公司」 |
| 开发完成日期 | `completedAt` | 早于或等于申请日；与说明书封面一致 |
| 发表日期 | `publishedAt` | 没对外发布就填「未发表」，别乱填 |
| 源程序量 | `ruanzhu count` 算出 | 与说明页、代码统计三处同一个数 |

## 先说谁来写

说明书和下面「开发目的」「面向行业」「主要功能」「技术特点」四项，**请本人照着软件亲手写**。
2026 年起申请材料要手抄声明「未使用 AI 开发编写代码、撰写文档或生成登记申请材料」；
AI 代写的描述也常编出软件里没有的功能，本身就是驳回风险。工具只帮你算字数、挑套话。

## 口吻

表单是给审查员看的，不是给投资人看的。照着自己写的软件平平实实地写，
像开发者本人坐下来填表那样：

- **写具体的东西**：菜单名、按钮名、文件格式、数据库名，别写「智能化」「一站式」「赋能」「全方位」
- **写用户能做什么**：「用户上传 Excel 后，软件按客户名称汇总」，别写「实现数据的高效处理」
- **长短不齐是正常的**：真人写的每条功能长短不一，没必要每条都是三句话
- **编号用「1、2、3、」**，别用「一、xx。二、xx。」小标题提纲，更别带 `**` `#` `-` 这些 Markdown 符号——网页表单不认，会原样显示
- **别每句都是「支持……」「实现……」开头**

`ruanzhu form` 会把上面这些毛病挑出来放在清单「口吻检查」一节，改不改自己定。

## 50 字上限字段

超一个字提交不了。工具会给每项算字数。

开发/运行环境六项，`ruanzhu init` 和 `ruanzhu form` 会按跑命令的这台电脑和项目依赖
（package.json / go.mod / pom.xml / requirements.txt 等）自动填初值，清单里标「自动推断」，核对一下就行。

### 开发的硬件环境（`devHardware`）

写开发机配置，CPU / 内存 / 磁盘。

> Intel Core i7-12700 处理器，16GB 内存，512GB 固态硬盘

### 运行的硬件环境（`runHardware`）

写运行机的**最低**配置。**必须低于开发环境**，否则逻辑上说不通。

> 双核处理器，4GB 内存，1GB 以上可用硬盘空间

### 开发该软件的操作系统（`devOS`）

**写代码时用的系统**，不是软件能跑的系统。这里是最高频的填反点。

> Windows 11

### 软件开发环境/开发工具（`devTools`）

IDE、运行时、构建工具、版本控制。

> Node.js 22、Visual Studio Code、Git

### 该软件的运行平台/操作系统（`runPlatform`）

软件能跑在哪些系统上，可以比开发系统宽。

> Windows 10 及以上、macOS 12 及以上、Linux

### 软件运行支撑环境/支持软件（`runtimeSupport`）

运行期依赖：解释器、浏览器、数据库、中间件。

> Node.js 18 及以上，Chrome 或 Chromium 浏览器

### 开发目的（`purpose`）

一句话：谁用、拿它干什么、省了什么事。

> 帮开发者把源代码和说明书排成软著要求的格式，页数一次算准，不用反复改 Word

### 面向领域/行业（`industries`）

列 3–5 个行业，别只写一个。

> 软件开发、知识产权服务、企业信息化、科技服务、教育

## 长文本字段

### 软件的主要功能（`mainFunctions`）

**500–1300 字，低于 500 会被驳回。**

最省事的写法：先一两句话说这是个什么软件，然后打开软件，**照着菜单或页面一个个写**，
每个功能写「用户在哪里点了什么 → 软件做了什么 → 得到什么」。菜单写完一般就够 500 字了，
不用硬凑「扩展机制」「容错机制」这种标题。

> 本软件是一款门店会员管理软件，店员在收银电脑上使用。主要功能如下：1、会员登记。
> 顾客报手机号即可开卡，店员可以补录姓名、生日，老会员再来时输入手机号后四位就能查到。
> 2、积分。每消费一元记一分，积分可以抵现金，抵扣比例在「设置」里改。……

对照反面例子（能过，但一看就是套话）：

> 一、智能会员管理。系统支持会员全生命周期管理，实现会员信息的高效录入与精准检索，
> 全面提升门店运营效率。二、积分体系。……

### 软件的技术特点（`techFeatures`）

100 字以内，写**做法上和别人不一样的地方**，不要重复「主要功能」。

> 分页在生成 PDF 之前就算好，超长的代码行按折行后的实际高度算，所以换字体、换电脑页数都不变。

## 编程语言

勾选项，可多选。工具会按收进材料的文件后缀自动推断并写进清单，核对一下即可。

## 上传材料

| 上传栏位 | 传什么 |
|---|---|
| 程序鉴别材料 | `①程序鉴别材料_…pdf` |
| 文档鉴别材料 | `②文档鉴别材料_说明书_…pdf` |
| 其他证明文件 | 公司申请：营业执照 + 权属证明；个人申请：一般不需要 |

文件名带 `①②③` 前缀是为了对应上传栏位，传错位置是很常见的低级失误。
